## 📖 About The Project

**React-Course-Shop** is a fully dynamic web application designed to simulate an online marketplace for educational courses. Built with a modern React frontend and a dedicated backend, this project aims to deliver a seamless user experience for browsing, viewing details, and (in future versions) purchasing courses online.

This project is currently in active development, with a clear modular separation between the client-side interface and the server-side logic.

## ✨ Current Features

Based on the latest commits, the application currently includes:

- **Course Listing & Browsing:** The core frontend is set up to display courses in a structured marketplace layout.
- **Dedicated Course Info Page:** A detailed view for each course has been implemented, offering in-depth information to the user.
- **Course Info Sidebar:** A dynamic sidebar component has been added to the course information page, designed to hold prerequisite details, course stats, or enrolment actions.
- **Structured Backend:** A backend directory has been initialized to handle data management and API requests.

## 🛠️ Built With

- **Frontend:** [React](https://reactjs.org/) · JavaScript · CSS · HTML
- **Backend:** Node.js (Initialized, services under development)
- **Key Concepts:** Multi-page navigation, component-based sidebar, dynamic data rendering
